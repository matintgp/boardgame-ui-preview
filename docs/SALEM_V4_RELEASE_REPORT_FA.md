# گزارش نسخه Salem V4 — ۱۸ اکتبر ۲۰۲۶

## دو خروجی مجزا و بدون تغییر بک‌اند اصلی

1. **دموی قابل‌بازی**: `https://boardgame-ui-preview.vercel.app/salem/` — در ریشه همین مخزن روی Vercel به‌صورت Static منتشر می‌شود.
2. **فرانت‌اند مستقل Next.js / React / TypeScript**: `salem/product/` — قابل Build است و برای اتصال به WebSocket و API بک‌اند اصلی آماده شده؛ هنوز جایگزین دموی روی Vercel نشده است.

## تغییرات عملی نسخه V4

### ظاهر، صدا و انیمیشن
- نوار جدید ترتیب چهار نوبت جاری و بعدی همراه آواتارها، نشانگر نوبت و حالت گوینده.
- اصلاح فضای رنگی شب، روز و توطئه، نور فعال دور بازیکن و نشان اختصاصی صاحب گربه سیاه.
- بازخورد سینمایی هنگام اجرای کارت، افشای Tryal، انتخاب گربه و پایان بازی.
- افکت صوتی کوتاه با WebAudio فقط بعد از رضایت کاربر؛ امکان غیرفعال‌کردن صدا، انیمیشن‌ها و افکت‌ها؛ پشتیبانی از Reduced Motion.
- انیمیشن کشیدن دو کارت و فضاسازی شروع شب، ماه، ابرها، مه و طلوع از نسخه قبلی حفظ شده‌اند.

### گیم‌پلی و تجربه کاربری
- کتابچه کارت‌ها با تصویر بزرگ، رنگ‌بندی دسته کارت و راهنمای کاربرد هر کارت.
- آموزش تعاملی پنج‌مرحله‌ای، قابل ردکردن/بازکردن در موبایل و دسکتاپ.
- تنظیمات ذخیره‌شونده در مرورگر شامل کنتراست، چیدمان فشرده، افکت‌های کوتاه، فضای صوتی و موشن.
- پایان بازی با نتیجه، آمار نوبت و بازمانده، شخصیت‌های بازیکنان و بازپخش متنی **رویدادهای عمومی**.
- تایم‌لاینِ ترتیب نوبت‌ها و مدیریت نمایش اطلاعات محرمانه از پیش حفظ شده‌اند.

### ساختار واقعی پروداکشن در پوشه `salem/product/`
- Next.js App Router با صفحه ورود به شناسه میز و مسیر `/match/[matchId]`.
- مدل‌های TypeScript برای `PublicMatch` و `PrivateMatch` کاملاً جدا؛ جلوگیری از پذیرش کلیدهای خصوصی در Projection عمومی.
- WebSocket با تلاش اتصال مجدد و بازیابی Snapshot، شناسه یکتا برای فرمان‌ها و `stateVersion` برای جلوگیری از اجرای حرکت روی وضعیت قدیمی.
- UI موبایل و دسکتاپ، نوار نوبت، وضعیت حضور/قطع ارتباط، نمای تماشاچی فقط-عمومی و تایم‌لاین وقایع.
- LiveKit با توکن مجاز سرور، اتاق ساحره‌ها، حالت شنونده روز، مجوز انتشار میکروفون برای صاحب نوبت، نمایش گوینده واقعی، کیفیت تماس، انتخاب میکروفون و بازکردن صدای خروجی.
- فرم گزارش تخلف (تقلب، سوءرفتار، AFK)، ارسال به API تأییدشده؛ هیچ تصمیم مدیریتی در مرورگر انجام نمی‌شود.

## کارهای باقی‌مانده و محدودیت‌ها

**نسخه چندنفره واقعی هنوز عملیاتی نیست.** مخزن بک‌اند `matintgp/boardgame-platform` با دسترسی فعلی GitHub قابل خواندن نبود. APIهای زیر باید به سرویس موجود متصل بشن و با دو یا چند حساب واقعی تست بشن:

- `GET /api/matches/:id/state`: Projection عمومی و خصوصی مخصوص کاربر.
- `POST /api/matches/:id/commands`: اعتبارسنجی سروری نوبت، کارت، نقش، هدف، رسید یکتا و نسخه.
- `wss://.../ws/salem?matchId=...`: Broadcast تغییرات عمومی و پیام خصوصی فقط برای صاحب نقش.
- `POST /api/salem/voice-token`: توکن کوتاه‌عمر LiveKit، عضویت اتاق و مجوز میکروفون فقط پس از اعتبارسنجی بک‌اند.
- `POST /api/matches/:id/reports`: دریافت و بررسی گزارش‌ها همراه احراز هویت و Rate Limit.

محاسبه نتیجه رأی ساحره‌ها، زمان‌های رسمی و RNG مخفی، وضعیت AFK/Replay و احراز دسترسی Spectator باید روی **سرور** اجرا و Audit بشن. مراقبت از اطلاعات حساس در فرانت‌اند، به‌تنهایی ضدتقلب نیست.

نسخه Next.js مستقل هنوز روی دامنه فعلی منتشر نشده تا تنظیمات Static Vercel و دموی تأییدشده از بین نره. ساخت Next.js در CI موفقه، اما پیش از پروداکشن نیاز به API واقعی، تنظیم محیط، تست مرورگرهای مختلف، سنجش پایداری LiveKit، آزمون امنیت و تست بار داره.

## نحوه اجرای پوشه محصول

```bash
cd salem/product
npm install
cp .env.example .env.local
npm run typecheck
npm run build
npm run dev
```

تنها `NEXT_PUBLIC_SALEM_WS_URL` و `NEXT_PUBLIC_SALEM_API_BASE` عمومی‌اند. کلید خصوصی LiveKit را هرگز در Next.js frontend یا متغیر `NEXT_PUBLIC_` قرار ندهید.
