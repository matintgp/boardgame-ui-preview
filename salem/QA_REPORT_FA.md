# گزارش بررسی Salem V2

**محدوده:** دموی محلی فرانت‌اند، بدون بک‌اند.

| سناریو | نتیجه |
|---|---|
| ساخت میز ۴ نفره در عرض ۳۲۰ پیکسل | موفق، بدون اسکرول افقی و خطای JS |
| ساخت میز ۶ نفره در عرض ۱۴۴۰ پیکسل | موفق، بدون اسکرول افقی و خطای JS |
| ساخت میز ۸ نفره در عرض ۷۶۸ پیکسل | موفق، بدون اسکرول افقی و خطای JS |
| ساخت میز ۱۰ نفره در عرض ۳۹۰ پیکسل | موفق، بدون اسکرول افقی و خطای JS |
| نمایش خصوصی نقش / Tryal و بستن مودال | موفق |
| انتخاب کارت و هدف، بازی کردن کارت و پایان نوبت | موفق |
| اجرای متوالی ربات‌ها تا بازگشت نوبت انسان | موفق |
| اجرای آزمایشی Conspiracy و بازگشت به نوبت‌ها | موفق |
| اجرای آزمایشی Night و گزارش بامداد | موفق |
| HTML مستقل با ۱۴ تصویر visible و بدون تصویر خراب | موفق |

**تذکر:** آزمون کامل/خستگی‌ناپذیر همه ترکیب‌های کارت، برد/باخت، نقش و قطع ارتباط انجام نشده است. اجرای خودکار سناریوهای اصلی جایگزین QA تولیدی نیست.

## تغییرات نسبت به Salem V1

- جایگزینی جریان نمایشی Day/Accuse/Vote/Night با موتور نوبت‌محور و رویدادهای Conspiracy و Night.
- شبیه‌سازی هوشمندانه‌تر (اما نه حرفه‌ای) کنش‌های رقیب‌ها.
- جلوگیری از افشای Tryal پیش از رسیدن به آستانه اتهام.
- محدود کردن کارت‌های معمول به بازیکنان دیگر.
- جلوگیری از دیده شدن کارت‌های خصوصی هنگام بسته بودن نمایش نقش.
- اصلاح ادامه نوبت رقیب پس از روشدن کارت Tryal.
- افزودن ذخیره، ادامه، ریست و گزینه سرعت ربات‌ها.
- تم سازگار با وب‌سایت؛ تمام آرت‌های تولیدشده نسخه قبلی حفظ شده‌اند.

## محدودیت‌های شناخته‌شده

- کارت‌های سبز و آبی منتخب بعضاً اثر ساده‌سازی‌شده دارند.
- قابلیت‌های خاص کاراکترهای Town Hall در موتور کامل نیست.
- تعامل‌های پنهان و انتخاب فرد نهایی در بعضی مرحله‌ها به منظور اجرای تک‌نفره ساده شده‌اند.
- داده‌های محرمانه در حافظه مرورگر وجود دارند؛ استفاده آنلاین نیازمند سرور authoritative و projection امن است.
- هیچ API، WebSocket، میکروفون یا سرویس واقعی در این دمو ایجاد نشده است.
