# Salem 1692 — Frontend Gameplay Demo V2

نسخه بازی‌پذیر و نمایشی Salem برای انتقال تجربه، مکانیزم و طراحی به تیم Next.js / React / TypeScript.

## اجرای دمو

از ZIP خارج کنید و `index.html` را باز کنید. فایل‌ها و همه تصاویر به صورت محلی همراه پروژه هستند. نیازی به بک‌اند یا اینترنت نیست.

## امکانات اجراشده

- ساخت میز با ۴ تا ۱۰ بازیکن و انتخاب نقش تستی (تصادفی/شهروند/جادوگر/کلانتر)
- کارت‌های Tryal مخفی: بی‌گناه، Witch و Constable، مطابق تعداد نقش پایه در نسخه پنجم قوانین
- شروع بازی با Black Cat در اختیار بازیکن انسانی
- نوبت واقعی: یا دو کارت بکشید و نوبت را واگذار کنید؛ یا یک یا چند کارت بازی کنید و سپس پایان دهید
- چند نمونه کارت قرمز / سبز / آبی با اثر در بازی
- روی هم جمع شدن امتیاز اتهام و افشای Tryal پس از رسیدن به هفت
- حذف بازیکن در صورت افشای Witch، افشای همه Tryalها یا حمله شبانه
- Conspiracy: چرخش Tryalهای پنهان و تغییر احتمالی تیم جادوگران
- Night: حمله، حفاظت کلانتر، اعتراف برای مصونیت و نمایش گزارش صبح
- شرایط برد تیم شهر و جادوگران
- رقیب‌های شبیه‌سازی‌شده، ذخیره‌سازی دمو در مرورگر، سرعت بالاتر AI و ریست
- تم تغییرپذیر برای روز/شب/توطئه، UI ریسپانسیو ۳۲۰ تا ۱۴۴۰ پیکسل

## محدودیت‌ها (حتماً برای تیم فرانت‌اند روشن باشد)

- این **یک شبیه‌ساز فرانت‌اند** است و قرار نیست منطق امنیتی نهایی از همین JavaScript گرفته شود.
- نقش‌ها و Tryalهای همه بازیکنان در حافظه محلی هستند و **در DevTools قابل دیدن‌اند**. در بازی چندنفره واقعی نباید اطلاعات محرمانه برای سایر بازیکنان ارسال شوند.
- فقط زیرمجموعه‌ای از کارت‌های بازی، با بعضی اثرهای تعدیل‌شده و ساده‌سازی شده برای UX اجرا شده‌اند. مهارت‌های اختصاصی Town Hall، تمام کارت‌های رسمی، دقیقاً همه شرایط Conspiracy/Night و تصمیم‌های دقیق بازیکنان انسانی هنوز کامل نیستند.
- حریف‌ها ربات‌های محلی ساده‌اند؛ هیچ هوش بازی پیچیده یا Matchmaking واقعی وجود ندارد.
- در بعضی رویدادها برای تست روان‌تر، انتخاب Tryal توسط بازیکن انسانی انجام می‌شود نه سیستم چندنفره مطابق اختیارهای کامل قوانین.
- تعداد ۴–۱۰ نفر برای دموست؛ بازی اصلی Salem معمولاً ۴–۱۲ نفره است.

## فایل‌ها

`index.html` — اسکلت و ساختار HTML دموی مرورگر

`assets/salem.css` — طراحی ریسپانسیو و تغییر فازها

`assets/salem-engine.js` — موتور نمایشی قوانین و جریان نوبت‌ها

`assets/*.png` و `assets/portraits/` — همه تصاویر تولیدشده در نسخه قبلی (بدون تغییر)

`NEXTJS_HANDOFF.md` — راهنمای جداسازی کامپوننت‌ها، مدل داده و وصل کردن APIهای فعلی

`screenshots/` — عکس‌های تست دسکتاپ و موبایل
